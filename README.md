# Vedic SBC Android APK

GitHub-ready Android project for building the Vedic Sarvatobhadra Chakra APK without Android Studio.

## Build on GitHub
1. Put the contents of this `VedicSBC` folder at the root of your GitHub repository.
2. Open **Actions**.
3. Run **Build Vedic SBC APK**.
4. Download the `Vedic-SBC-debug-apk` artifact.

## Build versions
- Android Gradle Plugin: 8.7.3
- Gradle: 8.9
- Java: 17
- compileSdk/targetSdk: 35

The workflow explicitly installs Gradle 8.9. This is required by the Android Gradle Plugin used by this project.
